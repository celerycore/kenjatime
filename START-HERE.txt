MUGEN WEB LAB — WEB EDITION 11

Open https://celerycore.github.io/kenjatime/ in a current browser.
Import a character, stage or engine ZIP, or load the Kung Fu Man sample.
On a phone, tap Import or browse files and choose a ZIP in Files/Downloads.
ZIP paths are normalized inside the archive. Missing external resources are reported.

Choose Training sandbox to run character CNS/CMD scripts and collision-based combat.
P1: arrows to move, Z/X/C and A/S/D to attack. Enter: start. R: reset.
P2: choose keyboard or CPU using the training controls.
The compatibility report lists unsupported behavior; full MUGEN compatibility remains unfinished.

The previous Arena interface is preserved at arena/index.html.
